# Street Soccer 3D

This project contains the Street Soccer 3D browser game and a small Express server for running it locally.

## Requirements
- Node.js 18 or newer
- npm

## Run the game
1. Open a terminal in this project folder.
2. Install dependencies: `npm install`
3. Start the server: `npm start`
4. Open `http://localhost:3000` in your browser.

## Run tests
Run `npm test` to check that the main game file and server entry point are present.

## Project folders
- `public/` — browser game files (`index.html`)
- `player/` — reserved for player-related assets or data as the project grows
- `test/` — basic project checks
- `server.js` — local web server
- `package.json` — scripts and dependencies
- `.gitignore` — files Git should ignore
